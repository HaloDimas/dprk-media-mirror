# Security Policy

## Reporting a vulnerability

If you find a security vulnerability in this project, please report it
privately — do not open a public issue, pull request or discussion about it.

- Email: **atsushi@tutanota.com** with a description of the issue, the
  affected page or file, and steps to reproduce if you have them.
- Or use **GitHub Security Advisories** on this repository
  (Security tab → "Report a vulnerability") to file a private report.

We will acknowledge your report, investigate, and let you know when a fix is
ready before any public disclosure.

## What not to do

- Do not post vulnerability details, proof-of-concept exploits, credentials,
  tokens, session cookies or webhook URLs in public issues, pull requests,
  discussions or screenshots.
- Do not test against the live site in a way that disrupts it for other
  visitors (no load testing, no mass requests, no attempts to access other
  people's data).

## Notes

- This project never asks contributors or users for passwords, session
  cookies or tokens. Anyone asking for them in the name of this project is
  not acting for it.
- The site mirrors third-party content; a vulnerability in an upstream source
  should be reported to that source, but you can still tell us so we can
  mitigate it on our side.
